## 0. Risks, dependencies and open questions (read first)

### Risks

1. **White text on orange fails WCAG AA for body text.** `#FFFFFF` on `#F26A1B` is 3.06:1. The rule is: never put white text on `accent`. Every text on an orange surface is navy (`text-on-accent`, 5.66:1). Orange text on white uses the darker `accent-strong` `#C2410C` (5.18:1). Acceptance includes a grep for `bg-accent` next to `text-white` or `text-on-brand`.
2. **Focus rings on three kinds of background (white, navy, orange).** No single colour passes on all three.
   - The plan is a CSS-variable ring: `var(--focus-ring, var(--color-accent-strong))`.
   - Dark regions set `--focus-ring: accent`.
   - The orange category bar sets `--focus-ring: brand`.
   - Native `<dialog>` drawers opened from inside the header inherit the header's variable through the DOM. `Drawer` and `Dialog` must reset it (section 4).
3. **`overflow-x-auto` also clips vertically.** It turns `overflow-y` into auto, so rings on links inside the horizontally scrolling category bar and category rail get cut off. Use inset rings (`focus-visible:outline-offset-[-3px]`) in the bar and `p-1` padding in the rail.
4. **Header width at 1024 px.** Wordmark, six nav links, search and cart add up to about 944 px against 960 px available. Mitigation: search is `lg:w-48 xl:w-64`. Screenshot 1024 as well as 375, 768 and 1280.
5. **Openverse photos.**
   - Supply is uneven; generic product-type queries return old or low-quality photos.
   - Anonymous API calls are rate-limited, so keep to about 40 queries and `sleep 2` between them.
   - Some source hosts block hotlinking or need redirects: use `curl -L` with a user-agent.
   - PDM labels are set upstream, so record the `foreign_landing_url` for every file.
   - Fallback per slot: a generated solid or gradient tile (section 7). Never picsum.
6. **Content rules on photos.** No cannabis buds or flower, joints, smoking, THC branding, faces, watermarks, text, or other brands' logos.
   - Queries containing "cbd", "cannabis", "marijuana" or "weed" are forbidden; they return exactly this content.
   - Each candidate is viewed with the Read tool before download is accepted, and again after processing.
7. **Home h1 is now the promo headline, not the brand statement.** This is acceptable for Phase 1.5. Phase 9 (SEO) may revisit it.
8. **Promo product missing after the Phase 2 DB swap.** If the slug is archived or deleted, the banner degrades (no price plate, CTA to `/shop`) and logs `console.error`. The home page does not throw.
9. **The old Phase 1 hero threw on a missing product.** That behaviour is removed on purpose.

### Hard content rules (reject if any apply)

- cannabis buds or flower
- joints, pipes, smoking or vaping
- THC or dispensary branding
- recognisable faces (hands are fine)
- watermarks
- visible text, labels or logos of any brand
- medical or pharmacy framing (pill-bottle labels)
- low resolution (under 1200 px on the short side for products and bands, under 600 for icons)

### Process per image

1. Read the JSON result and view the `thumbnail` or `url`.
2. `curl -L -A "haven-botanics-dev/1.0" -o <scratchpad>/raw/<name>.<ext> "<url>"`, then `file` to confirm it is a JPEG or PNG.
3. **View the raw file with the Read tool** and reject if it breaks the rules.
4. Convert:
   - Products and icons: `magick raw -auto-orient -strip -resize 1200x1200^ -gravity center -extent 1200x1200 -quality 78 -sampling-factor 4:2:0 -interlace JPEG out.jpg` (use `600x600` for icons).
   - Promo and bands: `-resize 1600x1200^ -gravity center -extent 1600x1200`.
5. Check the size with `stat -c %s`. If it is over 250 KB, re-run at `-quality 70`.
6. **View the processed file with the Read tool again** to check the crop didn't cut the subject.
7. Record a credits row.

### Fallback

If a slot has no acceptable result after three queries, generate a tile and note "generated, no source" in the credits. Never use picsum.

- products: `magick -size 1200x1200 radial-gradient:"#FFFFFF-#E8EAF6" out.jpg`
- icon variant: solid `#E8EAF6`
- band: `-size 1600x1200 radial-gradient:"#1C2470-#0B1150"`

# Addendum A: dispensary look, smoking accessories, hemp pre-rolls, and the new shop layout

Based on the code after R1/R2: `siteConfig.name = "Botanics"`, `photoPools` + `photo` in `src/mocks/catalog.ts`, 33 files under `public/images/`, `ProductFilters` inline at `lg` + drawer below, `Pagination` 5-number window, service default `pageSize` 12. Nothing here conflicts with R3. Shop grid classes are passed as props; `ProductGrid`/`ProductCard` defaults are unchanged.

## A0. Risks the user must read first

1. **Federal hemp redefinition (verify with counsel).** The November 2025 federal funding law redefines hemp by total THC (THCA included) and caps finished products at ~0.4 mg total THC per container, effective ~November 2026. If so, hemp flower/pre-rolls (and possibly full-spectrum tinctures) stop being legal hemp.
2. **State bans on smokable hemp.** List changes often; counsel must confirm. Phase 5 checkout would need state blocking; today the site can only disclose it.
3. **Payments.** CBD needs Stripe approval. Stripe prohibits "drug paraphernalia"; grinders, papers/cones and trays can be classed as paraphernalia even without THC. Smokable hemp is commonly declined. Get written processor approval before launch. Applies to A2 accessories too.
4. **Age.** Rolling papers/cones are tobacco components under federal Tobacco 21, so the site goes 21+ when papers ship.
5. **Bud photos** raise payment/ad-review flags, hence pre-rolls stay behind a flag.

## A1. Decisions

1. **Store name — user decides; do not rename yet.** Options: "Botanics Supply Co." (recommended), "Haven Hemp House", "Greenroom Hemp Co.". Avoid high/420/kush/dank/stoned/blaze. One-line change to `siteConfig.name`.
2. **Brand voice:** bolder, shorter, streetwise; sentence case; no THC, effect, medical or intoxication words. Slugs/ids/SKUs never change; only `name`, `shortDescription`, tagline, home copy (R7).
3. **Accessories = smoking gear, no nicotine/tobacco.** Six generic products replace dropper set, travel tin, journal, mug, tote; `gift-box` stays archived. Description: "Lighters, grinders, papers and cones, trays, smell-proof jars and ashtrays. No nicotine, no tobacco."
4. **Hemp pre-rolls: build hidden behind `siteConfig.features.smokableHemp` (default `false`).** New category `hemp-pre-rolls` with 4 products; when false, mocks filter the category and product seeds out entirely (not "draft"), so nothing leaks into bar, rail, search or `/shop/hemp-pre-rolls` (404). Phase 2 does the same by not seeding. Enabling (R8b) needs the user's written OK on counsel, processor and shipping-state plan. FAQ/terms state copy gated by the same flag. Photos only after enablement.
5. **Minimum age 21** when accessories ship (R6): `legal.ageNotice` "For adults 21 and over.", FAQ age answer and terms eligibility say 21.
6. **Shop layout:** no sidebar; "Filters"/"Filters (n)" button opens the existing `Drawer` at every width; active filter chips under the heading; URL params (`q`, `sort`, `min`, `max`, `stock`, `page`) unchanged; `ShopListing` passes page size 20 (service default stays 12).
